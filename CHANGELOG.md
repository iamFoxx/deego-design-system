# Changelog

## v1.0.0

- First public release of the `deego-design-system` skill.
- Multi-system structure: selection by name, context or default.
- `openai-editorial` system (default), with tokens, components, layout and notes on the source.
- Shared accessibility and HTML email rules.
- `_template` for new systems, validation (`scripts/check.py`) and packaging (`scripts/package.sh`).
- Automatic release with the zip on each `v*` tag.
